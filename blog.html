How to add a new blog post

  1. Create a new HTML file in the same folder as this page, for example blog-post-01.html.
  2. Copy the structure from the example below, and change the title, date, heading, and content text.
  3. Add a link to the new post in this blog homepage by creating another article block in the .blog-list section.
  4. Use plain HTML for math, images, and formatting. For LaTeX, you can either render equations with MathJax or embed screenshots/PNG images of the equation.

Example blog post template

<article class="blog-post"> <span class="blog-meta">April 2026</span> <h2>My post title</h2> <p>Introductory paragraph here.</p> <figure> <img src="files/my-image.jpg" alt="Description" /> <figcaption>Optional caption</figcaption> </figure> <p>Use standard HTML tags for paragraphs, lists, and emphasis.</p> <p>For mathematics, either use MathJax or write the equation as an image.</p> </article>

Recommended setup for LaTeX and images

  • Place images in a folder such as files/ or a dedicated subfolder like files/blog/.
  • Use descriptive filenames so they stay organized as your blog grows.
  • If you want equations to display properly, include the MathJax script in the page head:
<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>

Then write equations like:

$$ E = mc^2 $$

For simple posts, it is often easiest to keep text in HTML and use screenshots or uploaded images for equations if you want the exact look you prefer.
